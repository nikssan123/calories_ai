# The register, and where it came from
#
# These lines used to be written in an invented voice. content/copy/corpus.md
# measures the real one off production, and the headlines below are now
# written to it. Four things that report changed:
#
#  - Length. A typed entry is a median of 8 words, not the 4-word label the
#    parser keeps. The old cards were written at the parser's length.
#  - Numbers. 47.4% of typed messages carry a quantity. Half of these
#    headlines do too, because that is how often people actually say one.
#  - Shape. People capitalise and do not end-punctuate. So no full stops on
#    the headlines that are meant to read as somebody's entry.
#  - The line that was simply wrong. "No, I am not weighing my food" claimed
#    a behaviour the corpus contradicts — `грама` is the second most common
#    typed word. It is replaced by a card that says amounts are optional,
#    which is true either way and does not argue with the users.
#
# Structure: where a card has two lines, the headline is in the user's
# register and the subline answers in the product's. Food names are drawn
# from the corpus vocabulary (chocolate, eggs, feta, tomato, banana, toast,
# black coffee, rice) rather than invented.
#
# One card kept despite the data: "Am I eating enough protein?" Only 2 of 213
# messages are questions, so nobody is doing this yet. It is a feature claim,
# not a behaviour claim, and the feature ships — but do not expect it to be
# the card that lands.
#
# Three things deliberately absent:
#
#  - No competitor is named. CONTENT_ENGINE.md §5 lists naming them under
#    formats to avoid, so the comparison lines say "most apps" and stop there.
#  - Nothing implies the app is free. Coach and the packs exist, and a joke
#    that invites "wait, is it free?" in the replies is a joke that costs money.
#  - No claim that this one estimates *more accurately*. See below.
#
# The accuracy lines, and why they are phrased against ourselves too.
#
# The 2026 research (NUTRITION 2026, Hengist & Charles) put photo-based
# trackers 250-345 kcal and ~30g fat light per meal, and that finding is now
# the loudest thing in the category. It is tempting to attack it. We cannot:
# this app estimates from photos as well (`food_entries.source = 'photo'`),
# and there is no measurement showing ours is closer. A superiority claim we
# cannot produce a number for is the one credibility hit §0 says not to take.
#
# So the angle is not "theirs is wrong, ours is right". It is that every
# number in this category is an estimate, ours included, and the thing worth
# comparing is what it costs to fix one. That we can demonstrate on screen:
# item-level rows exist precisely so "there was more rice" updates a row
# rather than making you log the meal again. The researcher's own complaint
# -- "I had to correct it because it misinterpreted what's there" -- is a
# description of our correction flow, from someone who is not selling it.
#
# corpus.md §5 is explicit that none of its numbers may appear in a post.
# Nothing below quotes one. The data set the voice, not the claims.
#
# The last six lines came out of the vocabulary table, translated. The corpus
# is one writer -- the owner account, pre-release -- so it is a register
# reference and nothing else; it says how a sentence gets typed, not what a
# market wants. Each maps to a word that is actually in it and a feature that
# is actually shipped:
#
#   вчера (11), "forgot to log Sunday"  log_food's `when` takes plain language
#                                       ("yesterday 8pm") -- tools.ts:148, and
#                                       prompt.ts:157 calls a past day ordinary
#   "same as yesterday"                 repeat_meal copies rather than
#                                       re-estimates -- prompt.ts:151. The
#                                       subline is that comment's own reasoning
#   добави (10) още (6) малко (13)      "add a bit more", the correction flow
#   около (12) грама (24)               a hedge and a number in one breath;
#                                       47.4% of typed messages carry a number
#   чаена лъжица (7/8)                  a teaspoon, i.e. precision without scales
#   шоколад (17) десерт (13)            the sweet-tooth thread, already the
#   сладолед (7) сладък (8)             most-typed food in the corpus
#
# `бирени` (5) turned out to be beer sausage -- бирени наденички, a cured
# Bulgarian sausage, not the beer nuts I had guessed. It earns a card on
# sodium rather than on calories, which is the Diet Quality card's whole point.
#
# It also opened the language lines, which are the best claim in here and were
# nowhere in the copy. apps/api/src/ai/language.ts resolves the reply language
# from the *conversation*, not from `users.locale` -- that column is a
# rendering preference for the buttons, and answering from it once told a
# Bulgarian journal to reply in English translated word for word ("Barely a
# dent" came back as "барели дупка", the English word spelled in Cyrillic).
# The same file escalates the model for the ten measured languages the cheap
# one writes badly. Bulgarian is one of them.
#
# No Cyrillic on a card until a Cyrillic face is vendored: Baloo 2 has zero
# codepoints in U+0400-04FF (layout.tsx says so, and the ttf confirms it), so
# `бирени` on a card is four tofu boxes. Nunito is the app's Cyrillic display
# face and is not in assets/fonts yet.
